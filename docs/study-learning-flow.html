Study project architecture

학습이 지식과 장기 기억으로 이어지는 구조

입력과 회상

자료를 보기 전에 질문에 답해 현재 기억과 빈틈을 확인합니다.

이해와 적용

자기 언어로 설명하고 새로운 문제나 과제에 사용합니다.

장기 기억

핵심 구분과 오류를 인출 문항으로 만들고 간격을 두어 반복합니다.

통합 산출물

검증된 개념과 적용 결과를 연결해 자신만의 최종 교재로 만듭니다.
