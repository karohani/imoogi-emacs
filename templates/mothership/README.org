* Emacs 기본 명령
C-c n으로 모선 메인 메뉴를 연다. 처음 사용하는 장비에서는 S로 초기화한다.

| 키 | 동작 |
|----+------|
| o | 이 README 열기 |
| n | 분류 폴더와 제목을 선택해 새 Org 노트 만들기 |
| c | Inbox에 빠른 메모 만들기 |
| e | 전체 메타데이터 입력 폼 열기 |
| E | 목록형 속성 하나를 빠르게 선택하기 |
| f | 모선 전체에서 파일명으로 노트 찾기 |
| s | 모선 본문 검색 (ripgrep 필요) |
| i | 현재 Org 버퍼에 노트 ID 링크 삽입 |
| d | 모선 폴더를 Dired로 열기 |
| + | 부모를 골라 번호가 겹치지 않는 하위 폴더 만들기 |
| r | 기존 Org-roam 하위 메뉴 열기 |
| S | 초기화·빠진 폴더 복구 |

같은 제목의 파일은 번호를 붙여 보존한다. 기존 README는 초기화 명령으로 덮어쓰지 않는다.
하위 폴더 번호는 부모마다 독립적으로 01, 02처럼 붙이며 부모 번호를 이어 붙이지 않는다.
예: 30. Permanent Notes/01. 인공지능/01. 언어모델/
새 노트를 만들 때 하위 폴더도 선택할 수 있다. 기존 폴더는 자동 재번호하지 않는다.
Org-roam은 기존 ~/notes/permanent/를 사용하며 모선으로 자동 이전하지 않는다.
메타데이터 선택 목록은 M-x customize-variable에서 imoogi-mothership-property-values로 관리한다.
기본 항목은 TYPE·STATUS·CONFIDENCE이며 LAYER 등은 기준을 정한 뒤 추가할 수 있다.
폼에서 TAB/Shift-TAB으로 이동하고, C-c C-c로 적용하거나 C-c C-k로 취소한다.
적용은 원본 버퍼에만 반영하며 C-x C-s로 노트를 저장한다. ID·생성일·수정일은 읽기 전용이다.
MODIFIED 속성이 있는 모선 노트는 저장할 때 수정일을 갱신한다.

* 다시 읽을 운영 원칙
Mothership은 여러 프로젝트를 거치며 나의 지식과 관심사가 축적되는 본거지다.
프로젝트 노트는 각 프로젝트의 목적·작업·실험·판단·결과를 보존한다.
두 공간은 원본을 복사하는 대신 서로 연결한다.

- 질문을 중심으로 탐구한다. 자료를 모두 처리하는 것을 목표로 삼지 않는다.
- 현재 설명, 그 설명의 근거, 다음 행동을 남긴다.
- 출처의 주장과 내 해석을 구분한다.
- 프로젝트의 작업 상태는 프로젝트의 할 일 문서가 원본이다.
- 당시 기록은 보존하고 현재 이해는 새 근거에 맞춰 갱신한다.
- 모든 메모를 영구 노트로 만들거나 모든 단계를 통과시킬 필요는 없다.
- 숫자는 고정된 위치와 정렬을 위한 것이다. 파일의 성숙도나 이동 순서가 아니다.

Assets는 작성에 사용하는 구성 자원, References는 참조하는 외부 원본으로 구분한다.
중복되는 파일은 복사하지 않고 한 곳에 보관한 뒤 연결한다.
Atlas 전용 폴더는 만들지 않는다. 분야별 지도는 관련 폴더의 인덱스 노트로 작성하고 이 메인에서 연결한다.

* 반복 흐름: 질문 → 탐색 → 정리 → 적용 → 갱신
** 질문
무엇을 알아내려는가? 왜 지금 중요한가?
프로젝트에서 나온 질문은 해당 프로젝트에, 지속적인 관심에서 나온 탐구는 Process에 기록한다.
** 탐색
기존 지식·문헌·경험에서 근거를 찾고 관련 기록을 연결한다.
** 정리
근거를 비교해 현재 설명을 작성한다. 반대 근거와 아직 모르는 점도 남긴다.
** 적용
실험·작업·설명에 사용한다. 프로젝트에서 수행한 조건과 결과는 프로젝트 기록에 남긴다.
** 갱신
결과에 따라 설명을 수정한다. 재사용할 이해는 Permanent Notes에 정리하고 원래 기록을 연결한다.

* 작업을 시작하고 멈출 때
** 시작
- [ ] 오늘 다룰 질문과 현재 설명을 읽는다.
- [ ] 다음 행동과 관련 프로젝트의 원본 TODO를 확인한다.
** 마무리
- [ ] 무엇을 시도했고 실제로 무엇을 확인했는지 남긴다.
- [ ] 생각이 바뀌었다면 이유와 근거를 남긴다.
- [ ] 다음에 바로 시작할 수 있는 행동을 적는다.

* 주기적으로 다시 읽기
이 문서를 검토할 때 체크리스트를 읽고 필요하면 표시를 초기화한다.
자동 알림이나 반복 일정은 아직 설정하지 않았다.

- [ ] 운영 원칙과 폴더 경계를 다시 읽었다.
- [ ] Inbox에서 지금의 질문과 연결할 기록을 검토했다.
- [ ] 프로젝트에서 얻은 이해 중 중앙에 정리할 것을 살펴봤다.
- [ ] 새 근거 때문에 수정할 기존 설명이 있는지 살펴봤다.
- [ ] 중요한 질문과 프로젝트로 가는 연결을 갱신했다.
